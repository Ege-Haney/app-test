# Aralık Toplamı

Python'daki hesaplayıcı kodunun tarayıcıda çalışan arayüzü. Başlangıç ve bitiş
tam sayılarını girip kapalı, açık veya yarı açık aralığın toplamını hesaplayın.
Dört aralık seçeneğinin tümü ekranda görünür; yarı açık aralıkta başlangıç ya da
bitiş ucunun hariç tutulacağını doğrudan seçebilirsiniz.

## Çalıştırma

`index.html` dosyasını bir web tarayıcısında açın. Uygulama kurulum veya sunucu
gerektirmez.

Aralıklar Python `range()` davranışını izler: başlangıç bitişe eşit veya
bitişten büyük olduğunda toplam `0` olur. Hesaplama büyük tam sayılarda da
kesin sonuç verir.
